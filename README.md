# INSTRUCTIONS

This is a Codename Engine mod folder. Please put it in your CNE's mods folder. Then, in the main menu, press Tab and switch to "Five Nights At Freddy's 2", then press Enter!
Have fun! If there's any bugs or inconsistencies please report it in the issues tab.

Also, if you want to restart, press F6 and it will send you back to the warning screen.
If you want to switch mods, go to the FNAF title screen and press TAB.
